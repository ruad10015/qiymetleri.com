# qiymetleri.com Android app

Native Expo/React Native client for the public qiymetleri.com catalogue. The existing FastAPI backend remains the data source; admin functionality is intentionally excluded.

## Local setup

```powershell
Copy-Item .env.example .env
npm install
npm run android
```

The default `.env.example` URL targets the public FastAPI deployment. If that service or its database is unavailable, public catalogue reads transparently fall back to the latest retailer snapshot generated by `scraper/scripts/export_mobile_catalogue.py`. The snapshot contains real products, current prices, store links, and image URLs; it never fabricates price history. Set `EXPO_PUBLIC_API_URL` to another HTTPS endpoint to override the deployment.
